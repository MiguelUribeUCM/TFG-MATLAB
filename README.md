# TFG-MATLAB
Repositorio con los programas usados en el Trabajo de Fin de Grado, centrado en la resolución numérica de problemas inversos orientados al tratamiento y reconstrucción de imágenes. Incluye métodos deterministas como TSVD y regularización de Tikhonov, y métodos bayesianos y de muestreo MCMC, en particular Metropolis-Hastings y Gibbs Sampling.
